# AI를 활용한 디자인 워크플로우

AI를 활용하면 레퍼런스 탐색부터 디자인 시스템과 프로토타입 제작까지 빠르게 반복할 수 있다.

```text
요구사항 정리 → 무드보드 → 디자인 시스템 → 프로토타입 → 검토·수정
```

## 1. Pinterest로 무드보드 구성

무드보드는 제품이 전달할 분위기와 시각적 방향을 이미지로 모은 자료이다.

- 서비스의 사용자와 핵심 키워드를 먼저 정한다.
- Pinterest에서 색상, 타이포그래피, 레이아웃, 이미지 스타일을 수집한다.
- 비슷한 특징끼리 묶고 공통된 패턴을 찾는다.
- 단순히 예쁜 이미지를 모으기보다 제품 목적과 연결되는 이유를 기록한다.

## 2. AI로 디자인 시스템 작성

완성한 무드보드와 서비스 요구사항을 AI에 제공해 일관된 디자인 규칙을 만든다.

주요 구성 요소는 다음과 같다.

- 색상: Primary, Secondary, Background, Text, 상태 색상
- 타이포그래피: 제목, 본문, 캡션의 크기와 굵기
- 간격과 크기: 여백, 모서리, 버튼 높이
- 컴포넌트: 버튼, 입력창, 카드, 내비게이션
- 상태: 기본, Hover, Focus, Disabled, Error

AI가 만든 결과는 초안으로 사용한다. 색상 대비, 접근성, 반응형 화면, 컴포넌트 일관성은 직접 검토한다.

## 3. 프로토타입 생성

디자인 시스템을 바탕으로 핵심 사용자 흐름을 먼저 구현한다.

1. 사용자가 달성할 핵심 목표를 정한다.
2. 필요한 화면과 이동 순서를 구성한다.
3. AI로 화면 초안을 생성한다.
4. 실제 사용 흐름을 테스트한다.
5. 피드백을 반영해 디자인 시스템과 화면을 함께 수정한다.

AI의 장점은 첫 결과를 완성품처럼 사용하는 데 있지 않다. 여러 안을 빠르게 만들고 비교하면서 기획과 디자인을 구체화하는 데 있다.
