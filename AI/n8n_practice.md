# n8n 학습 정리 - 구글 설문 3개 완료 시 메일 발송 워크플로우

## 개요

이번 워크플로우는 **Google Form 3개가 모두 제출되었을 때만 메일을 발송하는 자동화**를 구현한 것이다.

하나의 설문 제출을 시작으로 다른 설문의 응답을 조회하고, 데이터를 병합한 뒤 모든 설문 작성 여부를 확인하여 조건을 만족하는 경우에만 메일을 발송한다.

---

# 전체 흐름

```text
설문1 제출
      │
      ▼
설문2 데이터 조회
      │
      ▼
설문1 + 설문2 데이터 병합
      │
      ▼
설문3 데이터 조회
      │
      ▼
설문1 + 설문2 + 설문3 데이터 병합
      │
      ▼
모든 설문 작성 여부 확인(IF)
      │
 ┌────┴────┐
 │         │
True      False
 │         │
 ▼         ▼
메일 발송   종료
```

---

# 워크플로우 구성

## 1. 설문1 제출 조회 (Trigger)

### 사용 노드

- Google Sheets Trigger (Row Added)

### 역할

설문1 응답 시트에 새로운 행(Row)이 추가되면 워크플로우가 자동으로 실행된다.

즉, 사용자가 설문1을 제출하는 것이 전체 자동화의 시작점이 된다.

```text
사용자 설문1 제출
        ↓
Google Form
        ↓
Google Sheet
        ↓
새로운 Row 생성
        ↓
n8n Workflow 실행
```

### 학습 내용

- Trigger Node 사용 방법
- 이벤트 기반(Event Driven) 워크플로우

---

## 2. 설문2 제출 조회

### 사용 노드

- Google Sheets (Read)

### 역할

설문2의 응답 데이터를 조회한다.

설문1을 제출한 사용자가 설문2도 제출했는지 확인하기 위한 데이터를 가져오는 단계이다.

### 학습 내용

- 외부 데이터 조회
- Google Sheets Read Node 사용

---

## 3. 설문1 + 설문2 데이터 병합

### 사용 노드

- Combine

### 역할

설문1과 설문2 데이터를 공통 컬럼(예: 이메일)을 기준으로 병합한다.

예시

```text
설문1

email        name
a@test.com   홍길동

설문2

email        age
a@test.com   28
```

↓

```text
병합 결과

email        name      age
a@test.com   홍길동     28
```

### 학습 내용

- 여러 데이터 소스 병합
- 공통 키를 기준으로 데이터 결합

---

## 4. 설문3 제출 조회

### 사용 노드

- Google Sheets (Read)

### 역할

설문3의 응답 데이터를 조회한다.

앞에서 병합된 데이터와 다시 결합하기 위한 준비 단계이다.

### 학습 내용

- 여러 데이터 조회
- 워크플로우에서 데이터 연결

---

## 5. 설문3 데이터 병합

### 사용 노드

- Combine

### 역할

설문1 + 설문2 데이터에 설문3 데이터를 추가하여 하나의 데이터로 만든다.

```text
설문1
      +
설문2
      +
설문3
      ↓
최종 데이터
```

### 학습 내용

- 다중 데이터 병합
- 단계별 데이터 처리

---

## 6. 설문 작성 여부 확인

### 사용 노드

- IF

### 역할

설문1, 설문2, 설문3의 데이터가 모두 존재하는지 확인한다.

조건을 만족하면 True Branch로 이동하고,

조건을 만족하지 못하면 False Branch로 이동한다.

```text
설문1 O
설문2 O
설문3 O

↓

True
```

또는

```text
설문1 O
설문2 X
설문3 O

↓

False
```

### 학습 내용

- 조건 분기(IF)
- Boolean 조건 처리

---

## 7. 메일 발송

### 사용 노드

- Gmail

### 역할

IF 조건이 True인 경우 메일을 자동으로 발송한다.

```text
모든 설문 완료

↓

메일 발송
```

### 학습 내용

- Gmail 연동
- 외부 서비스 실행(Action Node)

---

## 8. 종료

조건을 만족하지 못한 경우 아무 작업도 수행하지 않고 종료한다.

# 이번 워크플로우에서 학습한 n8n 핵심 개념

| 개념 | 사용 노드 | 학습 내용 |
|------|-----------|----------|
| Trigger | Google Sheets Trigger | 이벤트 발생 시 워크플로우 자동 실행 |
| Read | Google Sheets | 외부 데이터 조회 |
| Combine | Combine | 여러 데이터 병합 |
| IF | IF | 조건에 따른 실행 분기 |
| Action | Gmail | 외부 서비스 실행 |
| Workflow | 전체 | 노드를 연결하여 자동화 프로세스 구성 |

---

# 느낀 점

이번 실습을 통해 n8n의 기본적인 워크플로우 구성 방법을 익혔다.

단순히 노드를 연결하는 것이 아니라,

- Trigger를 통해 이벤트를 감지하고,
- 여러 데이터 소스를 조회 및 병합한 뒤,
- 조건에 따라 작업을 분기하고,
- 최종적으로 메일을 발송하는 전체 자동화 흐름을 구현해 보았다.

이를 통해 n8n이 **이벤트 기반(Event-Driven) 자동화 플랫폼**이며, 다양한 서비스를 연결하여 반복적인 업무를 자동화할 수 있다는 점을 이해할 수 있었다.
