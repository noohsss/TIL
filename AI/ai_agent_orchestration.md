# AI Agent 오케스트레이션과 루프 엔지니어링

## 오케스트레이션

오케스트레이션은 하나 이상의 AI Agent와 도구가 **정해진 순서와 규칙에 따라 협력하도록 전체 작업 흐름을 조정하는 것**이다.

주요 역할은 다음과 같다.

- 작업을 단계별로 나누고 담당 Agent를 선택한다.
- Agent에 필요한 도구와 문맥을 전달한다.
- 실행 상태와 결과를 다음 단계로 넘긴다.
- 오류, 재시도, 권한, 사람의 승인 절차를 관리한다.

단순한 작업은 하나의 Agent로 처리하는 편이 관리하기 쉽다. 역할이나 전문성이 명확히 나뉘는 복잡한 작업에서 여러 Agent를 고려한다.

## 루프 엔지니어링

루프 엔지니어링은 AI Agent가 목표에 도달할 때까지 **행동하고, 결과를 관찰하고, 검증하고, 수정하는 반복 구조**를 설계하는 방식이다.

```text
목표 설정 → 행동 → 결과 관찰 → 검증 → 수정 또는 종료
                ↑                 |
                └──── 재시도 ─────┘
```

좋은 루프에는 다음 요소가 필요하다.

- 명확한 목표와 완료 조건
- Agent가 사용할 문맥과 도구
- 테스트나 리뷰 같은 객관적인 검증 방법
- 최대 반복 횟수와 비용 제한
- 실패 시 재시도 또는 사람에게 넘기는 기준
- 진행 상태와 결과를 기록하는 방법

## 두 개념의 관계

- **오케스트레이션**은 누가 어떤 순서로 작업할지를 설계한다.
- **루프 엔지니어링**은 결과를 어떻게 검증하고 개선하며 언제 멈출지를 설계한다.

두 개념을 함께 적용하면 복잡한 Agent 작업을 반복 가능하고 안전한 흐름으로 만들 수 있다.
