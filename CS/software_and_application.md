# 소프트웨어와 애플리케이션

## 소프트웨어

하드웨어가 특정 작업을 수행하도록 만드는 **프로그램과 관련 데이터**이다.

## 실행 환경에 따른 구분

| 구분 | 실행 환경 | 특징 |
| --- | --- | --- |
| Web | 웹 브라우저 | 설치 없이 URL로 접근하며 업데이트가 쉽다. |
| App | 스마트폰·태블릿 | 기기에 설치하고 카메라, GPS 등의 기능을 활용할 수 있다. |
| Desktop | PC 운영체제 | PC에 설치하며 파일 시스템과 하드웨어를 폭넓게 사용할 수 있다. |

같은 서비스도 목적과 사용 환경에 따라 Web, App, Desktop 형태를 함께 제공할 수 있다.
