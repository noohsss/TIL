# 컴퓨터 하드웨어와 처리 방식

## 주요 하드웨어

| 구성 요소 | 역할 |
| --- | --- |
| CPU | 명령어를 해석하고 연산을 수행하는 중앙 처리장치 |
| MB(Mainboard) | CPU, RAM, 저장장치 등 부품을 연결하는 메인보드 |
| RAM | 실행 중인 프로그램과 데이터를 임시 저장하는 주 저장장치 |
| SSD | 데이터를 장기간 저장하는 빠른 보조 저장장치 |

RAM은 전원이 꺼지면 데이터가 사라지지만, SSD의 데이터는 유지된다.

## 멀티스레딩과 병렬 처리

- **멀티스레딩**: 하나의 프로세스 안에서 여러 스레드가 작업을 나누어 수행한다.
- **병렬 처리**: 여러 CPU 코어가 여러 작업을 실제로 동시에 수행한다.

멀티스레딩은 작업 구조에 관한 개념이고, 병렬 처리는 실행 방식에 관한 개념이다. 멀티스레드 프로그램도 CPU 코어가 하나라면 빠르게 번갈아 실행될 수 있다.
