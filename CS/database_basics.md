# 데이터베이스와 CRUD

## 데이터베이스(DB)

데이터베이스는 데이터를 **구조적으로 저장하고 필요한 정보를 빠르게 조회·관리하는 시스템**이다. 데이터베이스를 관리하는 소프트웨어를 DBMS(Database Management System)라고 한다.

## CRUD

CRUD는 데이터를 다루는 네 가지 기본 작업이다.

| 작업 | 의미 | SQL 예시 |
| --- | --- | --- |
| Create | 데이터 생성 | `INSERT` |
| Read | 데이터 조회 | `SELECT` |
| Update | 데이터 수정 | `UPDATE` |
| Delete | 데이터 삭제 | `DELETE` |

웹 애플리케이션은 보통 API를 통해 CRUD 요청을 받고, 서버가 데이터베이스에 해당 작업을 수행한다.

## SQL과 NoSQL

| 구분 | SQL | NoSQL |
| --- | --- | --- |
| 데이터 구조 | 행과 열로 구성된 테이블 | 문서, 키-값, 그래프 등 다양한 형태 |
| 스키마 | 구조가 명확하고 관계를 정의함 | 비교적 유연하게 변경 가능 |
| 관계 처리 | JOIN을 이용한 관계 표현에 강함 | 중첩 또는 분산 데이터 처리에 유리 |
| 대표 제품 | PostgreSQL, MySQL | MongoDB, Redis |

- **SQL**: 데이터 관계와 일관성이 중요하고 구조가 비교적 명확할 때 적합하다.
- **NoSQL**: 데이터 구조가 자주 변하거나 대규모 분산 처리가 중요할 때 유용하다.

어느 한쪽이 항상 우수한 것은 아니며, 데이터의 구조와 서비스 요구사항에 따라 선택한다.

## Supabase

Supabase는 **PostgreSQL을 기반으로 데이터베이스, 인증, 스토리지, 자동 API** 등을 제공하는 백엔드 플랫폼이다. 서버 기능을 빠르게 구성할 수 있지만, 테이블 구조와 접근 권한 정책은 직접 설계해야 한다.
