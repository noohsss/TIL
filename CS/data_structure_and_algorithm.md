# 자료구조와 알고리즘

## 자료구조

데이터를 **효율적으로 저장하고 관리하는 방식**이다.

- 배열: 데이터를 순서대로 저장
- 스택: 나중에 넣은 데이터를 먼저 꺼냄(LIFO)
- 큐: 먼저 넣은 데이터를 먼저 꺼냄(FIFO)
- 해시 테이블: 키를 이용해 값을 빠르게 탐색
- 트리·그래프: 계층 또는 연결 관계를 표현

## 알고리즘

문제를 해결하기 위한 **명확한 절차와 방법**이다. 검색, 정렬, 탐색 등이 대표적이다.

자료구조는 데이터를 담는 방법이고, 알고리즘은 그 데이터를 처리하는 방법이다. 적절한 자료구조를 선택하면 알고리즘의 시간과 메모리 사용량을 줄일 수 있다.
