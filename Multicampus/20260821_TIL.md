## Class(클래스)

클래스는 객체를 만들기 위한 설계도이다. 속성(데이터)과 메서드(기능)를 정의한다.

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def introduce(self):
        print(f"이름은 {self.name}, 나이는 {self.age}세입니다.")

person = Person("김철수", 25)
person.introduce()
```

### 핵심 개념

- **인스턴스**: 클래스로 만든 객체. `Person("김철수", 25)`
- **생성자 `__init__`**: 인스턴스가 만들어질 때 자동 실행
- **`self`**: 현재 인스턴스를 가리킴
- **인스턴스 변수**: `self.name`처럼 인스턴스마다 따로 가짐
- **인스턴스 메서드**: 인스턴스의 데이터를 사용하거나 변경하는 함수
- **클래스 변수**: 모든 인스턴스가 함께 사용하는 변수

```python
class Person:
    population = 0  # 클래스 변수

    def __init__(self, name):
        self.name = name
        Person.population += 1
```

### 매직 메서드

파이썬의 특정 기능을 사용할 때 자동으로 호출되는 메서드이다.

- `__str__`: `print(객체)`의 문자열 표현
- `__len__`: `len(객체)`의 반환값
- `__eq__`: `==` 비교 기준
- `__lt__`: `<` 비교 기준
- `__del__`: 객체가 삭제되기 전 정리 작업

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def __str__(self):
        return self.name

    def __eq__(self, other):
        return self.age == other.age
```

## 클래스 속성 및 메서드

데코레이터는 함수나 메서드의 동작을 확장하거나 변경한다.

### `property`와 `setter`

- `@property`: 메서드를 변수처럼 사용
- `@속성.setter`: 값을 할당할 때 유효성 검사

```python
class Person:
    def __init__(self, age):
        self._age = age

    @property
    def age(self):
        return self._age

    @age.setter
    def age(self, value):
        if value >= 0:
            self._age = value
```

### 클래스 메서드

`@classmethod`는 첫 번째 매개변수로 클래스(`cls`)를 받는다. 클래스 변수에 접근할 때 사용한다.

### 정적 메서드

`@staticmethod`는 `self`나 `cls` 없이 동작하는 독립적인 기능이다.

```python
class Person:
    @staticmethod
    def is_adult(age):
        return age >= 19

print(Person.is_adult(20))
```

## 데코레이터와 고차 함수

### 데코레이터

데코레이터는 기존 함수의 코드를 수정하지 않고 기능을 추가하는 함수이다.
`@데코레이터명` 형태로 사용한다.

```python
def trace_log(func):
    def wrapper(*args, **kwargs):
        print(f"{func.__name__} 호출")
        return func(*args, **kwargs)
    return wrapper

@trace_log
def greet():
    print("안녕하세요")

greet()
```

### 고차 함수

함수를 매개변수로 받거나 함수를 반환하는 함수이다.

```python
def execute(activity):
    return activity()

def run():
    return "달립니다."

print(execute(run))
```

### 일급 객체

파이썬의 함수는 일급 객체이므로 다음과 같이 사용할 수 있다.

- 변수에 할당
- 함수의 인자로 전달
- 함수의 반환값으로 사용
- 리스트나 딕셔너리에 저장

## 클래스 상속

상속은 부모 클래스의 속성과 메서드를 자식 클래스가 물려받아 재사용하는 기능이다.

### 단일 상속

```python
class Person:
    def __init__(self, name):
        self.name = name

    def walk(self):
        print(f"{self.name}이 걷습니다.")

class Student(Person):
    def study(self):
        print(f"{self.name}이 공부합니다.")

student = Student("김철수")
student.walk()   # 부모 메서드
student.study()  # 자식 메서드
```

### 메서드 오버라이딩

자식 클래스에서 부모 메서드를 같은 이름으로 다시 정의하여 동작을 변경한다.

### `super()`

부모 클래스의 생성자나 메서드를 호출한다. 부모 기능을 유지하면서 자식 기능을 추가할 때 사용한다.

```python
class Developer(Person):
    def __init__(self, name, language):
        super().__init__(name)
        self.language = language
```

### 다중 상속과 MRO

- **다중 상속**: 여러 부모 클래스를 동시에 상속
- **MRO(Method Resolution Order)**: 메서드를 찾는 순서
- `클래스.mro()`로 상속 순서를 확인할 수 있다.
